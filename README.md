Job Application Agent — setup guide

This repository hosts one page: a step-by-step guide for setting up your own copy of the Job Application Agent (a personal job discovery, scoring and recommendation pipeline).

It is published with GitHub Pages, so the only file that matters is index.html. There's no build step — GitHub serves it as-is.

Publishing / updating this page
Settings → Pages (in this repository)
Under Build and deployment → Source, choose Deploy from a branch
Branch: main, folder: / (root) → Save
GitHub gives you the live URL a minute or two later, usually https://<your-username>.github.io/<this-repo-name>/

To update the guide later, just edit index.html and push — Pages redeploys automatically on every push to main.

Note

This repo is meant to hold only this guide — not the Job Application Agent codebase itself, which lives in its own (private) repository.
